# Кладовка

Нужное для дома. Подберём под вашу задачу.

Сервис подбора домашних товаров с объяснением выбора, личной кладовкой и повтором покупок. Статический сайт без сборки, npm и внешних библиотек.

## Разместить на GitHub Pages

1. Распакуйте архив.
2. Загрузите **содержимое папки `kladovka` в корень своего репозитория**. `index.html`, `styles.css`, `catalog.js`, `selection.js`, `app.js` и папка `assets` должны находиться рядом.
3. Откройте в репозитории **Settings → Pages**.
4. В **Build and deployment** выберите **Deploy from a branch**, ветку **main** и папку **/(root)**. Нажмите **Save**.
5. Когда публикация завершится, GitHub покажет адрес сайта. Если сайт уже опубликован, достаточно заменить файлы в той же ветке.

Все пути относительные. Сайт работает по адресу с названием репозитория в пути. Разделы используют hash-навигацию.

## Что изменилось

- Название «Кладовка», тёплая терракотовая палитра, новые изображения и тексты.
- 9 категорий: уборка, стирка, кухня, хранение, свет и батарейки, мелкий ремонт, уход за обувью, товары для питомцев и растений.
- 14 сценариев с тремя отдельными вопросами для каждой задачи.
- Подбор учитывает совместимость, назначение и размеры. Несовместимые варианты не подставляются, если подходящего товара нет.
- 94 примера товарных позиций и вариантов, поиск, категории и сортировка по цене.
- Сохранение подходящих товаров, повтор заказа, корзина, выбор точки и даты получения.
- Календарь пополнения расходников: интервал, пауза и пропуск. Для долговечных вещей используется ручной повтор.
- Сохранение в текущем браузере, диалоги с управлением с клавиатуры.

## Основа ассортимента

Основные группы, задачи и критерии выбора адаптированы из листа «Ассортимент» проекта «Кладовка». В сайт не включены расчёты продаж, маржинальности и другие коммерческие показатели таблицы.

Цены, отдельные позиции и характеристики иллюстративные. Они не связаны с реальными остатками и поставщиками. Перед коммерческим запуском замените их проверенными данными конкретных товаров.

## Текущее состояние

Это работающий интерфейс прототипа. Заказы и настройки сохраняются в localStorage этого браузера. Оплата, фактическая выдача, уведомления, фоновые списания и синхронизация между устройствами пока не подключены. Выбор автопополнения сохраняет настройку; он не запускает реальные поставки.

Для приёма реальных заказов потребуется сервер с каталогом и остатками, база заказов, платёжная интеграция, подтверждённые точки выдачи и планировщик пополнения. Секреты интеграций должны храниться на сервере.

## Где редактировать

- `index.html`: страницы, навигация и тексты.
- `styles.css`: оформление и адаптивность.
- `catalog.js`: категории, сценарии, вопросы, товары и свойства для подбора.
- `selection.js`: правила сопоставления выбранных параметров и характеристик.
- `app.js`: корзина, личная кладовка, расписания и взаимодействия.
- `assets/`: локальные изображения, SVG товаров и значок сайта.

Изображение `assets/kladovka-hero.webp` создано для проекта с помощью ImageGen. Карточки содержат авторские SVG-иллюстрации.
